HeyClock USB-Only Setup

This version has:
- No Wi-Fi setup
- No Bluetooth setup
- USB setup only
- Saves device name, timezone, language, and alarm time

How to use:
1. Upload HeyClock_USB_Only_Setup.ino to the board.
2. Close Arduino Serial Monitor.
3. Run: npm install
4. Run: npm start
5. Open http://localhost:3000 in Chrome or Edge.
6. Connect HeyClock by USB.
7. Save setup.
